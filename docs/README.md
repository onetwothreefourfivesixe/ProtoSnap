# Documentation

Documents are grouped by the four parts of this fork (see "This fork" in the repository README). Each folder keeps
its own figures in `img/`.

## 1. Font tests — `font_tests/`

- [font_tests.md](font_tests/font_tests.md): This document covers ProtoSnap on photographed single signs with the
  Assurbanipal and Santakku font prototypes, and how far the fitted skeletons move from the font glyph.

## 2. Line cropping, first iteration — `line_cropping/`

- [pipeline_overview.md](line_cropping/pipeline_overview.md): This document explains the whole pipeline for readers who
  know OCR, with diagrams and sources. Start here.
- [line_cropping_plan.md](line_cropping/line_cropping_plan.md): This document gives the phase-by-phase plan and the
  findings of each phase.
- [metrics_comparison.md](line_cropping/metrics_comparison.md): This document lists every metric for the eBL and CDLI
  sets side by side. It is generated by `line_cropping/report/aggregate_metrics.py`.
- [data_cdli_artifacts_json.md](line_cropping/data_cdli_artifacts_json.md),
  [data_ebl_detection_2024.md](line_cropping/data_ebl_detection_2024.md): These are notes on the two external data sets.
- [plan.txt](line_cropping/plan.txt): This is the original task list the plan grew from.

## 3. Esagil skeletons — `esagil/`

- [esagil_results.md](esagil/esagil_results.md): This document shows ten random ProtoSnap results on Neo-Babylonian
  signs with the generated Esagil skeletons. It is generated by `experiments/esagil_skeletons/sampleResults.py`.

## 4. Custom line model — `line_model/`

- [line_model.md](line_model/line_model.md): This is the report on the learned line finder. It covers the summary, data
  and ground truth, model, read-out and crops, evaluation, results across runs and against other line finders, and
  limitations. Appendix A lists the experiments in order.
- [related_work.md](line_model/related_work.md): This document compares other line finders with the line model (Kraken
  retrained, and the Dencker et al. line network rebuilt) and gives the literature review behind the choice.
