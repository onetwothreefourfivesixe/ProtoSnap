# Documentation

Documents are grouped by the two sections of this fork (see "This fork" in the repository README): `protosnap/` for
the ProtoSnap additions and `line_segmentation/` for the custom line model. Each folder keeps its own figures in `img/`.

## ProtoSnap additions: font tests — `protosnap/font_tests/`

- [font_tests.md](protosnap/font_tests/font_tests.md): This document covers ProtoSnap on photographed single signs with the
  Assurbanipal and Santakku font prototypes, and how far the fitted skeletons move from the font glyph.

## Line segmentation, first iteration — `line_segmentation/v1/`

- [pipeline_overview.md](line_segmentation/v1/pipeline_overview.md): This document explains the whole pipeline for readers who
  know OCR, with diagrams and sources. Start here.
- [line_cropping_plan.md](line_segmentation/v1/line_cropping_plan.md): This document gives the phase-by-phase plan and the
  findings of each phase.
- [metrics_comparison.md](line_segmentation/v1/metrics_comparison.md): This document lists every metric for the eBL and CDLI
  sets side by side. It is generated by `line_segmentation/report/aggregate_metrics.py`.
- [data_cdli_artifacts_json.md](line_segmentation/v1/data_cdli_artifacts_json.md),
  [data_ebl_detection_2024.md](line_segmentation/v1/data_ebl_detection_2024.md): These are notes on the two external data sets.
- [plan.txt](line_segmentation/v1/plan.txt): This is the original task list the plan grew from.

## ProtoSnap additions: Esagil skeletons — `protosnap/esagil/`

- [esagil_results.md](protosnap/esagil/esagil_results.md): This document shows ten random ProtoSnap results on Neo-Babylonian
  signs with the generated Esagil skeletons. It is generated by `protosnap_ext/esagil_skeletons/sampleResults.py`.

## Line segmentation: custom line model — `line_segmentation/`

- [line_model.md](line_segmentation/line_model.md): This is the report on the learned line finder. It covers the summary, data
  and ground truth, model, read-out and crops, evaluation, results across runs and against other line finders, and
  limitations. Appendix A lists the experiments in order.
- [related_work.md](line_segmentation/related_work.md): This document compares other line finders with the line model (Kraken
  retrained, and the Dencker et al. line network rebuilt) and gives the literature review behind the choice.
